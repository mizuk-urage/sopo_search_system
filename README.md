# sopo_denki_search_system

**バージョン: 1.0.11（2026-11-22）** — GitHub Pagesの公開内容と照合する目印です。初期データは空です。

電力シートなどの資料を登録して、企画番号・企画名・キーワード・テント番号などを検索する静的Webアプリです。初期状態は空で、例の企画やPDFは配布用アプリに含まれません。資料を追加すると企画ごとのページを作り、電力シート・配線図の該当ページを確認できます。スマートフォン・PCのブラウザーで動きます。

## 起動

データが空の検索画面をPCで確認するには `standalone.html` を開きます。端末から資料を登録する場合と、スマートフォンへホーム画面追加する場合は、GitHub PagesなどHTTPSのURLから開いてください。`data/data.json` を更新したときは `node build-standalone.js` で単体版も更新できます。

ホーム画面への追加とService Workerによるキャッシュを使う場合は、プロジェクトフォルダーで静的HTTPサーバーを起動してください。Pythonがある環境では:

```text
python -m http.server 8000
```

ブラウザーで `http://localhost:8000/` を開きます。スマートフォンで使うには、同じWi-Fi内からアクセスできる端末でサーバーを起動し、HTTPSで公開してください。スマートフォンでは対応ブラウザーのインストールボタン、またはブラウザーの共有・メニューからホーム画面に追加できます。

GitHub Pagesへ公開した後は、スマートフォンで公開URLを開きます。Androidなど対応ブラウザーでは画面に「アプリをインストール」ボタンが表示された場合に押します。iPhone/iPadではSafariの共有メニューから「ホーム画面に追加」を選びます。OSの確認操作は必要です。

## PDF表示と配色

企画ページの電力シート・配線図は、PDF1ページ全体が表示窓の幅に収まるサイズで表示され、左右にスワイプすると次のページへ移動します。配線図は企画名が見つかったページを強調しつつ、全ページを横スワイプで見られます。ページは画面の近くに来た時にPDF.jsで描画し、離れたページの画像メモリーを解放するため、スマートフォンで長い図面を開く負荷を抑えます。以前の表示はPDFをBlob URLの`iframe`でブラウザー内蔵PDFビューアへ渡していました。この方式は端末側の埋め込みPDFビューアに依存するため、スマートフォンのブラウザーがBlob URLのPDF埋め込みに対応しない場合、エラーや空白になります。現在は同梱PDF.jsでページをアプリ内に描画し、オフラインでも閲覧します。

屋外企画に控室が登録されている場合、屋外配線図に加えて屋内配線図も関連資料に載せます。控室欄に「なし」「無」「-」がある場合は対象外です。

画面はオレンジ（主操作）、水色（補助面と注目表示）、濃い青（リンク）、黒に近い文字色、明るいグレー背景で構成します。通常文字は背景とのコントラスト比4.5:1以上を基準とし、色だけに頼らずラベルや枠線でも状態を示します。基準は[WCAG 2.2のコントラスト要件](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)です。

## データの初期状態

`data/data.json` は空の初期データです。アプリを公開した後、利用者が「資料の登録」から電力シートPDFを登録すると、その端末に企画ページが作られます。以前の会話で使ったサンプル資料は配布用アプリとは別の `C:\Users\4927c\Documents\sopo_search_system_test_samples` に保管しています。

## ファイル

- `app.js`, `index.html`, `project.html`, `styles.css`: 検索・企画詳細ページ・表示。通常のデータ更新では触りません。
- `standalone.html`: `data/data.json` を内包した、サーバーなしで開ける版。データ更新後に `node build-standalone.js` で再生成します。
- `data/data.json`: 企画データ（更新対象）。
- `data/`: 公開する共通企画データ。初期状態では企画0件です。共通PDFを配布する場合は `data/pdfs/` に置き、JSONの `references` に登録します。
- `pdf-import.js`, `vendor/pdfjs/`: オフラインの電力シート抽出部品と日本語フォント・文字コード表。
- `icons/`: PC・スマートフォンのホーム画面に追加するためのアイコン。
- `service-worker.js`, `manifest.webmanifest`: オフライン保存とホーム画面インストール。
- `DESIGN.md`, `DATA_FORMAT.md`, `MAINTENANCE.md`, `DISTRIBUTION.md`, `AI_HANDOFF.md`: 設計・データ形式・保守・配布・AI引継ぎ。
- `tests/search.test.js`: 検索ルールの基本テスト。

## オフライン利用

**PC・スマートフォンとも、最初に一度オンラインで開いて保存が完了すれば、以降はオフラインで使えます。** スマートフォンと、アップロード資料もオフライン保存したいPCでは、HTTPSで公開したURLをSafari（iPhone/iPad）、Chrome（Android）、またはChrome/Edge（Windows/macOS）で開いてホーム画面／アプリに追加してください。Service Workerが画面・企画データ・参照PDFを保存します。保存が終わる前に接続を切らないでください。PCでZIP内の `standalone.html` を直接開く方法は、企画検索と同梱PDF閲覧向けです。ブラウザーの制約により、アップロード保存にはインストール済みアプリを使ってください。

画面から追加した資料PDFと企画ページは、その端末・ブラウザーのIndexedDBに保存するため、保存後はそのブラウザーでオフライン検索できます。ほかのブラウザーや端末には同期されません。検索一覧には企画ページだけを表示し、企画名を押すと独立した企画ページへ移動します。登録PDFは企画ページ内の関連資料から開きます。配線図はPDFを登録したときに端末内でページ別に文字を読み取り、企画名があるページを表示します。見つからない場合は配線図全体を表示し、その旨を明記します。以前の版で登録した配線図は、更新後に端末内で再読み取りしてページ別検索情報を追加します。配線図の検索用文字も端末内に保存され、通信なしで検索できます。企画ページ内のPDFはPDF.jsでページ画像として表示し、スマートフォンの埋め込みPDF表示に依存しません。差し替えた枠の旧ファイルは端末保存から削除します。電力シート登録後は資料登録画面に留まり、検索画面へ移動しません。データや同梱PDFを更新したら `service-worker.js` のキャッシュ名末尾を変更し、利用者に一度オンラインで再読み込みしてもらいます。

電力シートPDFはPDF.jsを使って端末内で読み取り、企画番号・企画名・団体名・場所・許可電力・出典ページを候補として作ります。企画一覧ファイルは不要です。読み取り結果は登録前に確認・修正できます。企画ごとに、そのページから次の企画の直前までを参照ページとして個別ページに表示します。文字情報が入っていないスキャンPDFからのOCRは行いません。配線図PDFは同じエリア属性で登録すると各企画ページの関連資料に表示します。PDFは埋め込みビューアではなく、PDF.jsでページ画像として表示します。

## 資料の追加・差し替え

「資料の登録」タブで、配線図は屋内・屋外の各1枠に登録します。電力シートは屋内・屋外それぞれで「エリア別に複数ファイル」または「全体を1ファイル」を選び、表示された各項目から登録・差し替えます。屋内の項目は第三エリア・第二エリア・第一エリア・体芸エリア・その他、屋外は第二・第三エリア・石の広場周辺・第一エリア・松美池周辺・会館エリア・体芸エリアです。「企画を登録」ボタンはPDF選択ボタンの隣にあり、読み取り後に有効になります。現在のファイル名は項目ごとに表示されます。置き換えの確認後、配線図はすぐに差し替わり、電力シートは企画情報を確認して登録すると差し替わります。登録ファイルと企画ページはこのブラウザーだけに保存されます。アプリ側ではファイルサイズに固定上限を設けていませんが、保存できる容量は端末・ブラウザーの空き容量やメモリによって異なり、大容量PDFは失敗する場合があります。

## 資料を追加して探す

検索一覧には企画ページだけを表示します。電力シートは選択した全ファイルから企画情報を抽出し、企画番号ごとに統合して確認・修正後、企画ごとのページにします。検索語は各ファイルから抽出した文字情報を対象にします。PDFは企画ページ内の関連資料から開けます。スキャン画像だけのPDFはOCRしません。

追加ファイルはIndexedDBを使って登録したブラウザーの端末内に保存されます。サーバーへ送信されず、同じURLを使う他の人・他の端末とも共有されません。複数人で同じ資料を使う場合は、資料を `data/pdfs/` などの公開フォルダーに置き、企画データの `references` に登録して配布してください。追加ファイルはブラウザーの保存領域を使うので、容量の大きいPDFを多数登録する用途には向きません。
